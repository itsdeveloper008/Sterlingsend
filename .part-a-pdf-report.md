# Part A: One renderer for screen, print and PDF

Branch `redesign`. Artefacts in `.perf/pdf/` (gitignored). Script: `node scripts/pdf-quality-parta.mjs http://127.0.0.1:3103`.

## Architecture

| Path | Behaviour |
|------|-----------|
| **Screen** | `EditableInvoiceCard` (`[data-invoice-builder-card]`) + template CSS vars |
| **Print** | `window.print()` + `@media print` on the live sheet (**vector text**). Chrome hidden. `thead` repeats; rows `break-inside: avoid`. |
| **Download** | Live card → `html2canvas` (scale so width ≥ 2400px) → JPEG 0.82 → jsPDF A4 with row-aware page breaks + opacity-0 text layer |

Shared for History `/invoices/[id]/pdf`, guest preview, public invoice: `InvoiceSheetPreview` + `downloadSheetPreviewPdf`.
