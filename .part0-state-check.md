## Download PDF and Print (after `b002a1b`)

| Path | How it works |
|------|----------------|
| **Print** | `window.print()` on the builder page. `@media print` in `invoice-builder.css` hides chrome and keeps colour on the live `[data-invoice-builder-card]` sheet. **Vector text** (browser print), not an image. |
| **Download PDF** | `downloadBuilderInvoicePdf` selects the live `[data-invoice-builder-card]`, adds `body.builder-pdf-export` to hide chrome, then `downloadInvoicePdf` in `pdf/utils/download.ts`. |
| **Library** | `html2canvas` (raster) + `jspdf` (`addImage` PNG onto A4 pages). |
| **Scale** | `html2canvas({ scale: 2 })` against sheet width (≥ `PDF_PAGE_WIDTH_PX`). |
| **What renders** | The same React sheet (`EditableInvoiceCard` / builder card), not `InvoicePDFTemplate`. |

Known gap for Part A: History Download and `/invoices/[id]/pdf` may still use the old `InvoicePDFTemplate` path until unified.
